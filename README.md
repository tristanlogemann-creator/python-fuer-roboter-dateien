Python für Roboter - Projekt-Dateien zum Download
===================================================

Diese Dateien enthalten den vollständigen Code aller 10 Projekte und
Bonus-Projekte aus dem Buch, direkt lauffähig zum Kopieren auf den
Hub bzw. in eure Entwicklungsumgebung.

teil2_pybricks/  (LEGO SPIKE Prime, Pybricks Web-IDE)
  - staubsauger_roboter.py       Kapitel 2.7
  - pid_linienfolger.py          Kapitel 2.8
  - alarmanlage.py               Kapitel 2.9
  - roboter_tanz.py              Kapitel 2.10 (Bonus)
  - greif_roboter.py             Kapitel 2.11

teil3_ftrobopy/  (fischertechnik TXT 4.0, ftrobopy)
  - ampelsteuerung.py            Kapitel 3.4
  - linienfolger_proportional.py Kapitel 3.5
  - sortiermaschine.py           Kapitel 3.6
  - parkschranke.py              Kapitel 3.7 (Bonus)
  - foerderband_uebergabe.py     Kapitel 3.8

Wichtig: wheel_diameter und axle_track in den Pybricks-Projekten sind
Beispielwerte (56 mm / 114 mm) - an eurem eigenen Roboter nachmessen
und anpassen (siehe Kapitel 2.4/2.5)! Ebenso müsst ihr bei den
Pybricks-Motoren ggf. positive_direction umdrehen, falls euer Roboter
sich nur dreht statt geradeaus zu fahren (siehe Kapitel 2.4).

Für Teil 3: Python lokal installieren und "pip install ftrobopy"
ausführen, siehe Kapitel 3.1.
